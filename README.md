# DataAnalisys

--Tecnologias utilizadas

Python
Pandas
Matplotlib
Jupyter Notebook


--Intuito da análise

Realizar uma análise exploratória de dados de vendas de um e-commerce, utilizando uma base com 5.000 registros. Foram analisados faturamento, preços, categorias de produtos, quantidade de pedidos, tempo de entrega, avaliações dos clientes e outros indicadores, buscando identificar padrões e pontos relevantes para o negócio.

--Conclusão

A análise permitiu identificar que as categorias de Eletrônicos e Roupas apresentaram desempenho superior em relação às demais, enquanto Beleza e Casa tiveram resultados menores. Também foi observado um desempenho mais baixo nas vendas em 2035 e não foi identificada uma relação significativa entre as avaliações dos clientes e variáveis como preço, desconto, quantidade e prazo de entrega, deixei tudo organizado em um PDF ja anexado
